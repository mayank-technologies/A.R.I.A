# ARC

JARVIS/EDITH-inspired AI voice assistant built in Flutter.

## Features
- Gemini Live voice-to-voice (male voice, expressive/emotional tone)
- Multi-language (Hindi, English, Hinglish, and more)
- App control, contact calling, WhatsApp automation
- Weather, calendar, reminders, news, cricket scores
- Anti-theft siren guard
- Screen vision/OCR
- Hardware controls (flashlight, WiFi, Bluetooth, volume, brightness)

## Note
This is a personal/testing project — debug APK builds only, not production-signed.
